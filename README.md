> **반려동물과의 소중한 모든 순간을 기록하다, Petory**
> Petory는 반려동물의 건강 상태를 체계적으로 관리하고 일상을 기록하는 스마트 케어 애플리케이션입니다.

---

## 📖 프로젝트 소개
**Petory**는 소중한 가족인 반려동물의 건강 정보(체중, 진료 기록 등)를 한눈에 파악하고, 매일의 추억을 사진과 함께 기록할 수 있도록 돕는 서비스입니다. AI 상담 기능을 통해 궁금한 건강 정보도 손쉽게 물어볼 수 있어요! 🐶🐱
