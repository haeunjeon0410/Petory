# Petory 🐾

> **반려동물과의 소중한 모든 순간을 기록하다, Petory**

## 📖 프로젝트 소개
**Petory**는 반려동물을 키우는 사용자들을 위한 반려동물 건강관리 및 기록 애플리케이션입니다.  

### 📅 개발 기간
* 2026.01.08 ~ 2026.01.14

### 🛠 기술 스택 (Tech Stack)
* **Language**: Dart
* **Framework**: Flutter
* **Design**: Figma
